The [Validation evidence subset](../evidence/validation_reference/) contains the
unchanged completed aggregate summary, completion receipt, and original analysis
source, with labeled public metadata extracts. It concerns an exploratory post
hoc comparison: Validation was excluded from gradient training but used in
development and model selection. The [offline verification guide](REPRODUCIBILITY.md#verify-saved-outputs-in-a-fresh-clone)
distinguishes package consistency from full scientific replication.

Other documents here are historical engineering records from metadata
acquisition, preprocessing, cohort/split locking and normalization. Their
phase-specific statements describe their time of writing, not the final study.
